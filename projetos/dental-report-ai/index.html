Dental Report AI

Transforma fotos de fichas clínicas preenchidas à mão em um relatório de estágio odontológico pronto para entregar em PDF.

Segmento
Sistemas & IA
Entrega
Automação · IA aplicada
Status
Código aberto
Tecnologias
Next.js 15 · TypeScript · Claude API · Tesseract.js · jsPDF · React Hook Form · Zod
Ver repositório

Estudo de caso

Como foi construído

O problema, as decisões de arquitetura e os desafios técnicos que apareceram no caminho.

Problema

O relatório de estágio da clínica é montado a partir de fichas de papel: dados do paciente, situação do tratamento e a contagem de cada procedimento. Transcrever isso à mão é demorado, repetitivo e fácil de errar na soma — e o erro só aparece depois de entregue.

Solução

O aluno fotografa as fichas; o sistema lê as imagens, estrutura os dados e monta o relatório. Tudo fica editável antes de exportar: a automação adianta o trabalho, mas a palavra final continua sendo de quem assina o documento.

Arquitetura

Upload das fotos
   │
   ├─ Caminho A ──→ POST /api/extract ──→ Claude (visão) ──→ JSON estruturado
   │                    (a chave da API fica só no servidor)
   │
   └─ Caminho B ──→ Tesseract.js no cliente ──→ parser próprio ──→ JSON estruturado
                              │
                              ↓
        Formulários editáveis (React Hook Form + Zod)  ← revisão humana
                              ↓
        Pré-visualização A4 ──→ html2canvas ──→ jsPDF ──→ PDF

Desafios técnicos

  • Ler ficha manuscrita com layout irregular.OCR genérico devolve texto embaralhado. Escrevi um parser específico para esse formulário: busca por rótulo, normalização de acentuação e maiúsculas, e leitura da próxima linha significativa quando o valor não está na mesma linha do rótulo.
  • Não confiar cegamente na extração.Todo campo extraído passa por validação com Zod e entra num formulário revisável.
  • PDF fiel à tela— a pré-visualização é o próprio documento, capturada e paginada em A4.

Minha responsabilidade

Projeto inteiro: fluxo de upload, integração com a API da Claude no servidor, parser de OCR, formulários, pré-visualização e geração do PDF.

Resultado

Fluxo completo funcionando do upload ao PDF, com dois caminhos independentes de extração e a credencial nunca exposta ao navegador.
